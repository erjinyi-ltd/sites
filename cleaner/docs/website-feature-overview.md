# GCSA Mac Cleaner

**本地优先的 macOS 清理与系统管理工具**

GCSA Mac Cleaner 帮助你看清 Mac 上的空间占用、应用残留与系统状态，在动手之前先看清影响，再以最小权限完成你明确确认的操作。它不是“一键优化”，而是把每一次清理都做成可审查、可确认、默认可恢复的流程：

**扫描 → 逐项复核与选择 → 影响预览与二次确认 → 执行并逐项报告结果**

支持 macOS 14 及更高版本。界面提供 English、简体中文、繁體中文。

---

## 为什么选择 GCSA

### 默认可恢复

默认清理方式是移到废纸篓。永久删除不会悄悄发生：它必须在设置中显式开启，且许多高影响场景会强制忽略该设置，继续走废纸篓。

### 不替你做高风险决定

任何一次全新扫描完成后，选中集合为空。个人文件、下载、大文件、iCloud 文件、浏览器站点数据永远不会进入自动推荐。

### 证据不足就停止

路径越权、符号链接逃逸、扫描后文件身份变化、关联应用仍在运行、权限不足——任一条件成立即阻止执行，而不是“尽力而为”。

### 完全本地

不含遥测、分析、账号登录、远程扫描报告或文件上传。扫描、历史、设备信息都只在当前 Mac 处理与保存，无需联网即可完成本地扫描与清理。

## 两种版本

| | **GCSA Mac Cleaner（完整版）** | **GCSA Cleaner（Lite）** |
|---|---|---|
| 获取方式 | Developer ID 签名并公证的 DMG | Mac App Store / TestFlight |
| 适合谁 | 需要完整清理、应用管理与系统诊断的用户 | 只想在自己授权的文件夹里找大文件与重复文件的用户 |
| 文件范围 | 产品固定允许范围 + 你选择的范围 | 仅你明确授权的目录 |
| 删除方式 | 废纸篓；设置中可开启普通文件永久删除 | 仅废纸篓 |
| 额外入口 | App、只读 CLI、Finder 扩展、受限 Helper | 单一 Store App |

两个版本是独立构建与独立安全边界，不是同一个 App 里关掉几个开关。

## 完整版功能

### 1. 垃圾清理

统一扫描用户自有位置中的可清理内容，包括：

- 用户缓存与已识别的 App 缓存
- 浏览器缓存、Cookie 与站点数据
- 用户日志与临时项目
- 下载文件夹
- 较大文件（≥ 512 MiB）
- 可选：已下载到本机的 iCloud Drive 文件（默认关闭，不会触发远端占位文件下载）

密码、书签、浏览历史和浏览器扩展被明确排除，不会进入候选列表。

你可以用搜索、排序与九个分段筛选（推荐、浏览器、App、用户缓存、用户日志、临时项目、下载、大文件、iCloud）快速定位。每一行都会展示归属应用、类型、大小、修改时间、扫描原因与推荐理由。Cookie / 站点数据会单独标为高影响，并在确认时提醒可能退出登录。

**推荐选择很克制：** 只有修改时间可信、至少 24 小时未变化、且未关联当前运行中应用的条目，才会进入“仅使用推荐”。运行中应用相关条目无法被选中。

### 2. 开发者清理

面向开发环境的缓存与构建产物清理，覆盖约 46 条发布规则，包括：

- Xcode DerivedData、Archives、DeviceSupport、Simulator
- `node_modules`、SwiftPM `.build`、CocoaPods Pods
- Homebrew 缓存与下载
- 常见包管理器、开发工具与 AI 工具缓存

每条规则都会说明用途、重建成本、风险、关联应用、运行进程与恢复策略。只有可变、低风险、已进入 release 阶段的规则才能进入推荐选择。确认页会精确展示：移到废纸篓、永久删除、被阻止的数量。执行前会重新生成计划并与已确认计划比对；任一关键变化都会要求重新复核。

### 3. 应用管理

管理 `/Applications` 与 `~/Applications` 中的应用，提供三种明确模式：

| 模式 | 做什么 | 删除方式 |
|---|---|---|
| **卸载** | 移走 App 本体，并默认选中高置信度专属关联文件 | 始终废纸篓 |
| **重置** | 保留 App，清理高置信度缓存与日志 | 可跟随设置 |
| **残留清理** | 清理已删除 App 留下的高置信度可再生成数据 | 可跟随设置 |

同时提供本机 **App 安全审计**：签名有效性、签名身份、Team ID、证书链、Gatekeeper、公证证据、Stapled 票据、App Sandbox、Hardened Runtime、安装来源、架构、最低系统版本、技术栈等。检查只使用本机 Security 框架与系统工具，**不联网调用公证服务**。“未知来源”只表示本地证据不足，不代表恶意。

受保护应用、运行中应用、允许目录外的应用、符号链接、身份异常项都会被阻止。也可以把合法 `.app` 拖入进行复核，确认前不会做任何删除。

### 4. 重复文件

选择一个或多个文件夹后：

1. 按大小分组，再按内容哈希确认重复
2. 选择保留策略（不自动选择 / 保留最新 / 保留最旧 / 保留最短路径）
3. 逐项复核，可选在 Finder 中查看
4. 确认后移到废纸篓

**每组至少保留一份。** 整盘、用户主目录、用户 Library、受保护系统路径、云同步根、App/图库等包、符号链接文件夹都不会被接受。重复文件清理始终走废纸篓，即使开启了直接删除也不会永久删除。

### 5. 恢复中心

完整版提供应用内恢复中心，可查看可恢复事务与条目，支持整事务恢复或单项恢复。

- 有可靠废纸篓目标的普通文件与 App 可恢复
- 经安全备份的 LaunchDaemon 可在校验通过后恢复
- 原位置已被占用时，使用唯一的 `Recovered` 名称，**绝不覆盖现有文件**
- 永久删除、维护动作、缺少目标信息的旧记录不可自动恢复

清理历史保存在本机 Application Support 目录，不会上传。

### 6. System Data

扫描 iOS 备份、Xcode、Docker、虚拟机、浏览器缓存、邮件与信息附件、AI 模型与缓存、App Store / Adobe 缓存等占用来源，但**只有通过安全策略准入的用户级缓存与可再生成数据**才会作为可清理项。快照、备份、虚拟机、浏览器资料、模型数据等被刻意排除；若只发现被排除项，界面会说明“未找到安全的清理项”，而不会把它们变成可选项。

### 7. Dock 与启动台

把标准应用目录中的 App 分类为 URL Handler、后台 App、更新器、普通 App。只有证据充分的辅助类候选项可清理，普通应用始终只读展示。另可单独执行“刷新启动台”：重建当前用户 LaunchServices 缓存并重启 Dock。

### 8. 登录项与扩展

合并查看：

- **App 后台活动**：登录项、后台任务、LaunchAgent/Daemon、Quick Look、Spotlight 等记录与状态
- **LaunchAgents / LaunchDaemons**：Label、程序路径、RunAtLoad、KeepAlive、安全分类与可用操作

僵尸用户 LaunchAgent 可走普通清理。系统项、受保护 Apple / GCSA 守护进程、元数据异常项只读。经用户批准的受限 Helper 后，可对符合条件的第三方 LaunchDaemon 执行“停用并备份”（可恢复）或“强制删除 plist”（不可恢复，需手动输入完整 Label）。

### 9. 系统维护

提供 8 项固定、可预览命令的维护任务：

- 刷新 DNS 缓存
- 重建 LaunchServices
- 重置 Quick Look 缓存
- 重启 Finder / Dock / 菜单栏服务 / 通知中心 / 控制中心

每项都会展示影响等级、支持版本、命令预览与恢复建议，执行前必须确认。维护历史仅供审计，不可自动“撤销”。

### 10. 隐私权限

在授予完全磁盘访问后，可读当前用户的 TCC 隐私授权记录，按相机、麦克风、辅助功能、完全磁盘访问、文件与文件夹、屏幕录制等分组展示。受支持的记录可按“服务 + Bundle ID”精确重置；路径型、未知服务与本地网络权限只会引导打开对应系统设置，不会直接改写系统隐私数据库。

### 11. 设备信息

只读展示本机可观察信息：

- Mac 型号、序列号、硬件 UUID、固件等
- 处理器与显卡、内存插槽
- 存储容量、可用空间、介质与协议、可用空间趋势与低空间预测（需足够历史样本）
- 电池健康度、循环次数、适配器功率
- 已连接 USB / Thunderbolt 设备的协商速率与供电能力

界面会诚实说明：无法可靠识别线材品牌、认证等级，也不能凭适配器功率证明快充。

### 12. 活动监控

按父子关系展示进程树，显示 CPU、内存占用（RSS）与可见网络端点。默认约每 2 秒刷新，可暂停。这是只读诊断页，**不提供结束进程**。

### 完整版附带入口

- **Finder 扩展**：在 Finder 中打开 GCSA Mac Cleaner，或把 `.app` 送到应用管理复核；扩展本身不做扫描或删除。
- **只读 CLI**：以 JSON 输出磁盘概况与维护能力目录，不能扫描删除候选项，也不能执行清理或连接 Helper。
- **受限特权 Helper**：仅白名单三种操作（读取后台任务、管理符合条件的 LaunchDaemon、恢复已备份的 LaunchDaemon），双向校验代码签名，不接受任意命令或密码。

## Lite 版功能（GCSA Cleaner）

Lite 是刻意收窄的单页应用，只做你明确授权范围内的复核：

1. **授权文件夹** — 选择一个或多个目录；主目录整体、用户 Library、系统目录、各类包与符号链接逃逸会被拒绝
2. **扫描授权目录** — 汇总文件数、扫描体积、重复组与大文件
3. **大文件复核** — 列出 ≥ 100 MiB 的文件
4. **重复文件复核** — 按大小分组后计算内容摘要，保证每组至少保留一份
5. **在 Finder 中显示**
6. **移至废纸篓** — 执行前逐项重新校验；本版本不提供永久删除

适合希望在 App Store 沙盒边界内，安全地清理自己选定文件夹中的大文件与重复副本的用户。

## 安全与权限

- 首次启动提供权限中心说明：完全磁盘访问、文件与文件夹、系统 Helper；授权不是进入主应用的前提。
- 缺少权限时，仍可使用不受影响的能力，并清楚说明受限范围。
- 权限恢复后，最多自动重试一个待处理的**只读扫描**；清理等破坏性操作永不自动执行。
- 所有真实文件修改与系统维护都需要二次确认；取消后系统保持不变。
- 批量操作返回逐项结果；部分失败不会伪装成全部成功。

## 明确不做的事

GCSA Mac Cleaner **不是**杀毒软件、EDR、内存清理器或自动系统优化器。以下能力不在当前产品范围，也不会用模糊文案暗示已支持：

- 相似照片识别与照片图库清理
- 可视化磁盘地图
- 通信应用的深度会话 / 附件管理
- 文件迁移助手、云账号与跨设备同步
- 自动 RAM 清理、进程终止、一键加速
- 任意第三方系统服务、任意 shell / root 命令
- 绕过 SIP、直接写入 TCC 数据库、自动清空废纸篓、自动删除 Time Machine 快照
